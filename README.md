## 🚀 С чего начать

1. Установи [Anki Desktop](https://apps.ankiweb.net/) и скачай нужную колоду по ссылке выше.
2. Импортируй файл `.apkg` в Anki Desktop.
3. В основной колоде открой **00. Инструкция (“Instrukcja”)**. Чтобы прочитать карточку целиком, нажми **«Показать ответ»**.
4. Синхронизируй коллекцию с телефоном и дождись полной загрузки звука и изображений на обоих устройствах. 📲

**Как сочетать колоды:** изучай слова в основной, затем закрепляй знакомую лексику в предложениях. Сначала выполняй повторы, потом переходи к новым карточкам. Если занимаешься с обеими колодами, учитывай общую дневную нагрузку.

Подробности установки, настройки предложений и обновления: **[инструкция](docs/START_HERE.md)**.
