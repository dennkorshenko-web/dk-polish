## 🚀 С чего начать

1. Установить [Anki Desktop](https://apps.ankiweb.net/) и скачать выбранную колоду по ссылке выше.
2. Импортировать файл `.apkg` в Anki Desktop.
3. В основной колоде открыть **00. Инструкция (“Instrukcja”)**. Полный текст карточки доступен по кнопке **«Показать ответ»**.
4. Синхронизировать коллекцию с телефоном и дождаться полной загрузки звука и изображений на обоих устройствах. 📲

**Как сочетать колоды:** слова изучаются в основной колоде, затем знакомая лексика закрепляется в предложениях. Рекомендуется сначала выполнять повторы, затем переходить к новым карточкам. При использовании обеих колод учитывается общая дневная нагрузка.

Подробности установки, настройки предложений и обновления: **[инструкция](Инструкции/README.md)**.
