# 🌐 Сайт DK-Polish

**[Открыть онлайн-словарь](https://dkpolish.github.io/dk-polish/)**

На сайте можно знакомиться с колодами, переворачивать примеры карточек с иллюстрациями и слушать их озвучку, искать польские слова и русские переводы, выбирать части речи и проверять себя со скрытыми переводами.

В примерах на главной кнопка звука доступна на польской стороне карточки. Озвучка запускается по нажатию; в направлении RU → PL она доступна после открытия ответа.

В режиме «Слово» рядом с польским словом показана оригинальная картинка из колоды. В направлении RU → PL картинка открывается вместе с польским ответом. В режиме «Предложение» доступны пример употребления и его озвучка.

<details>
<summary>Для редактирования сайта: назначение файлов</summary>

- `index.html` – главная страница с колодами и словарём.
- `assets/` – оформление, работа поиска, словарь и примеры.
- `assets/experience.js` – интерактивные примеры карточек на главной странице.
- `assets/audio/` – оригинальная польская озвучка примеров на главной.
- `assets/demo-images/` – оригинальные иллюстрации пяти слов в интерактивных карточках.
- `assets/social-preview.png` и `.svg` – обложка для ссылок на проект и её редактируемый оригинал.
- `sitemap.xml` – карта сайта для поисковых систем; содержит основной адрес без поисковых фильтров.
- `downloads/` – таблица Excel, доступная для скачивания на сайте.
- `.nojekyll` – служебный файл для публикации через GitHub Pages.
- `START_HERE.md` и `VOCABULARY.md` – переходы со старых адресов документов.

GitHub Pages публикует эту папку из ветки `main` после успешных автоматических проверок. Проверяются ссылки, картинки, аудио, словарь и основные действия в Chromium и WebKit, включая мобильный макет. Результат и отчёт доступны в [GitHub Actions](https://github.com/dkpolish/dk-polish/actions/workflows/site.yml).

При ошибке проверки новая версия не публикуется, предыдущий сайт продолжает работать. Для запуска проверок файлов используется `python scripts/check_site.py`, для браузерных сценариев – `npm ci`, `npx playwright install chromium webkit` и `npm test` из корня репозитория.

Метатег `google-site-verification` в `index.html` сохраняет подтверждение сайта в Google Search Console и должен оставаться при обновлениях.
