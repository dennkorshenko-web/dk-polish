# 🌐 Сайт DK-Polish

**[Открыть онлайн-словарь](https://dennkorshenko-web.github.io/dk-polish/)**

На сайте можно искать польские слова и русские переводы, выбирать части речи, раскрывать примеры и проверять себя со скрытыми переводами.

| Что нужно | Ссылка |
| --- | --- |
| Скачать таблицу для занятий | [📥 Excel](https://dennkorshenko-web.github.io/dk-polish/downloads/DK-Polish_Words_RU.xlsx) |
| Открыть полный список слов на GitHub | [📋 Материалы](../Материалы/README.md) |
| Прочитать, как пользоваться сайтом и Anki | [🚀 Инструкции](../Инструкции/README.md) |
| Выбрать и скачать колоду Anki | [📚 Главная страница проекта](../README.md) |

<details>
<summary>Для редактирования сайта: назначение файлов</summary>

- `index.html` – страница словаря.
- `assets/` – оформление, работа поиска, словарь и примеры.
- `downloads/` – таблица Excel, доступная для скачивания на сайте.
- `.nojekyll` – служебный файл для публикации через GitHub Pages.
- `START_HERE.md` и `VOCABULARY.md` – переходы со старых адресов документов.

GitHub Pages публикует эту папку из ветки `main`.

</details>
