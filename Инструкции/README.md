## Как пользоваться онлайн-словарём

**[Сайт DK-Polish](https://dkpolish.github.io/dk-polish/)** доступен на компьютере и телефоне. Он работает в браузере, без регистрации и установки.

1. Поиск работает по польскому слову или русскому переводу. Поддерживается ввод без польских букв: `czlowiek` найдёт `człowiek`.
2. Фильтр по частям речи ограничивает список выбранной категорией.
3. Кнопка **«Примеры»** под словом открывает предложения с переводами.
4. Кнопка **«Скрыть переводы»** включает режим самопроверки. Каждый перевод можно открыть отдельно.
5. Кнопка **«Скачать Excel»** загружает таблицу. В файле есть общий список, вкладки по частям речи и столбец для заметок.

Для занятий с интервальными повторениями используется Anki. Доступные колоды перечислены ниже.

## Выбор колоды

| Колода | Подойдёт для |
| --- | --- |
| [Polish Top 2000 (RU)](https://ankiweb.net/shared/info/1828156755) | Изучения слов, значений, форм и примеров употребления |
| [4200+ Polish Sentences (RU)](https://ankiweb.net/shared/info/189146153) | Закрепления слов в контексте и тренировки понимания на слух |

Можно использовать одну колоду или обе. Каждое слово и каждое предложение создаёт две карточки, поэтому дневной лимит считает направления повторения отдельно.

## Установка и синхронизация

1. Установить [Anki Desktop](https://apps.ankiweb.net/) на компьютер.
2. Скачать выбранную колоду с AnkiWeb и импортировать файл `.apkg` в Anki Desktop.
3. При первом импорте колоды оставить отключённым импорт чужого прогресса обучения.
4. В основной колоде открыть **00. Инструкция (“Instrukcja”)** и прочитать обе карточки инструкции. Продолжение доступно по кнопке **«Показать ответ»**.
5. Синхронизировать Anki Desktop с аккаунтом AnkiWeb.
6. Войти в тот же аккаунт в приложении Anki на телефоне и запустить синхронизацию. Дождаться завершения загрузки медиа на обоих устройствах.

## Как заниматься

- Рекомендуется сначала выполнять повторы, затем переходить к новым карточкам.
- В основной колоде можно начать с **5–10 новых карточек в день**, постепенно подбирая комфортную нагрузку.
- При использовании обеих колод учитывается общий объём новых карточек и повторов.
- При накопленных повторах можно временно установить **0 новых карточек** и сосредоточиться на повторении.

## Настройки колоды предложений

Рекомендуемые значения для самостоятельных занятий с предложениями:

- **Новых карточек в день:** 20.
- **Максимум повторяемых в день:** 9999.
- **Порядок отбора новых:** По возрастанию № позиции.
- **Порядок новых:** По порядку отбора.
- **Порядок новых (к повторяемым):** Показывать после повторяемых.
- **FSRS:** включён. **Желаемое усвоение:** 90%.
- **Откладывание:** все три пункта включены.

При одновременном изучении обеих колод рекомендуется уменьшить число новых карточек с учётом общей нагрузки. Лимит в 20 карточек относится к двум направлениям, а не к 20 предложениям.

При указанном порядке новые карточки идут блоками по **25 исходных слов** с чередованием частей речи. Когда слова категории заканчиваются, в следующих кругах она пропускается. Уроки и части речи можно найти по тегам.

## Как обновить колоду

Обновления общих колод AnkiWeb нужно скачивать и импортировать вручную.

1. Синхронизировать текущую коллекцию и создать её резервную копию.
2. Скачать новую версию по той же ссылке AnkiWeb.
3. Импортировать `.apkg` в текущий профиль, сохранив существующую колоду.
4. Проверить отчёт импорта и несколько карточек, затем синхронизировать устройства вместе с медиа.

Anki умеет обновлять ранее импортированные записи. Если поля или шаблоны изменялись вручную, перед импортом рекомендуется проверить параметры обновления типов записей: они определяют, какие изменения будут приняты. [Подробнее в документации Anki](https://docs.ankiweb.net/manual/importing/packaged-decks).

## Если нет звука или изображения

- Дождаться завершения синхронизации медиа.
- Проверить громкость и запустить звук вручную.
- На компьютере открыть **«Инструменты → Проверить медиа»**. Если обнаружены отсутствующие файлы, результат проверки можно сохранить и приложить к обращению.
- В основной колоде изображения есть у большинства слов; у части записей картинки изначально нет.
