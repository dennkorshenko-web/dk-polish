## Как пользоваться онлайн-словарём

Открой **[сайт DK-Polish](https://dennkorshenko-web.github.io/dk-polish/)** на компьютере или телефоне. Он работает в браузере, без регистрации и установки.

1. Введи польское слово или русский перевод в строку поиска. Можно писать без польских букв: `czlowiek` найдёт `człowiek`.
2. Выбери часть речи, если хочешь смотреть только одну категорию.
3. Нажми **«Примеры»** под словом, чтобы открыть предложения с переводами.
4. Для самопроверки нажми **«Скрыть переводы»**, затем открывай нужный перевод отдельно.
5. Для работы с таблицей нажми **«Скачать Excel»**. В файле есть общий список, вкладки по частям речи и столбец для заметок.

Для занятий с интервальными повторениями установи Anki и выбери колоду ниже.

## Выбери колоду

| Колода | Подойдёт для |
| --- | --- |
| [Polish Top 2000 (RU)](https://ankiweb.net/shared/info/1828156755) | Изучения слов, значений, форм и примеров употребления |
| [4200+ Polish Sentences (RU)](https://ankiweb.net/shared/info/189146153) | Закрепления слов в контексте и тренировки понимания на слух |

Можно использовать одну колоду или обе. Каждое слово и каждое предложение создаёт две карточки, поэтому дневной лимит считает направления повторения отдельно.

## Установка и синхронизация

1. Установи [Anki Desktop](https://apps.ankiweb.net/) на компьютер.
2. Скачай нужную колоду с AnkiWeb и импортируй файл `.apkg` в Anki Desktop.
3. Если импортируешь колоду впервые, оставь отключённым импорт чужого прогресса обучения.
4. В основной колоде открой **00. Инструкция (“Instrukcja”)** и прочитай обе карточки инструкции. Нажми **«Показать ответ»**, чтобы увидеть продолжение.
5. Синхронизируй Anki Desktop со своим аккаунтом AnkiWeb.
6. Войди в тот же аккаунт в приложении Anki на телефоне и запусти синхронизацию. Дождись завершения загрузки медиа на обоих устройствах.

## Как заниматься

- Сначала выполняй повторы, затем переходи к новым карточкам.
- В основной колоде можно начать с **5–10 новых карточек в день**, постепенно подбирая нагрузку под себя.
- Если используешь обе колоды, учитывай общий объём новых карточек и повторов.
- Если накопились повторы, временно поставь **0 новых карточек** и разберись с ними.

## Настройки колоды предложений

Рекомендуемые значения для самостоятельных занятий с предложениями:

- **Новых карточек в день:** 20.
- **Максимум повторяемых в день:** 9999.
- **Порядок отбора новых:** По возрастанию № позиции.
- **Порядок новых:** По порядку отбора.
- **Порядок новых (к повторяемым):** Показывать после повторяемых.
- **FSRS:** включён. **Желаемое усвоение:** 90%.
- **Откладывание:** все три пункта включены.

Если учишь обе колоды одновременно, уменьши число новых карточек с учётом общей нагрузки. Лимит в 20 карточек относится к двум направлениям, а не к 20 предложениям.

При указанном порядке новые карточки идут блоками по **25 исходных слов** с чередованием частей речи. Когда слова категории заканчиваются, в следующих кругах она пропускается. Уроки и части речи можно найти по тегам.

## Как обновить колоду

Обновления общих колод AnkiWeb нужно скачивать и импортировать вручную.

1. Синхронизируй текущую коллекцию и сделай её резервную копию.
2. Скачай новую версию по той же ссылке AnkiWeb.
3. Импортируй `.apkg` в текущий профиль, сохранив существующую колоду.
4. Проверь отчёт импорта и несколько карточек, затем синхронизируй устройства вместе с медиа.

Anki умеет обновлять ранее импортированные записи. Если ты самостоятельно менял поля или шаблоны, перед импортом проверь параметры обновления типов записей: они определяют, какие изменения будут приняты. [Подробнее в документации Anki](https://docs.ankiweb.net/manual/importing/packaged-decks).

## Если нет звука или изображения

- Дождись завершения синхронизации медиа.
- Проверь громкость и попробуй запустить звук вручную.
- На компьютере открой **«Инструменты → Проверить медиа»**. Если проверка нашла отсутствующие файлы, сохрани её результат и приложи к обращению.
- В основной колоде изображения есть у большинства слов; у части записей картинки изначально нет.
